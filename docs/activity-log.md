### Handoff briefing for the next session — crucial/sensitive logic

Things that aren't obvious from reading the code cold, and would be easy to break silently:

- **Checkpoint-sync ordering invariant**: `_onlyoffice_checkpoint_sync(doc)` must always run *before* `doc.status` changes in memory and before `doc.save()` — `Document.save()` compares old vs. new status to decide whether to bump `current_version`/create an `Archives` row. Reverse the order and the archived snapshot silently captures stale content. Repeated at every transition point in `documents/views.py` and `committee_level/views.py`.
- **`amendment_status is None` sentinel**: means "Insert Amendments was never opened this SECOND_READING session" (see item 5 above). If the reset-to-`None` logic in `move_to_second_reading`/`move_to_third_reading` ever changes without updating the new guard, the guard breaks silently.
- **`gazette_publiccomment` (`PublicComment` model)** is an unmanaged, read-only mirror of a separate system's table — real citizen names/comments/IP addresses (CLAUDE.md's "no customer personal data" rule applies directly). Django's FK is `on_delete=DO_NOTHING` but the real Postgres FK has no cascade, so deleting a `Document` can hard-fail with an FK violation unless those rows are cleaned up first (hit this directly this session).
- **`DOCUMENT_EDITOR_STORAGE_ROOT`** is deliberately kept outside `MEDIA_ROOT` so working `.docx` files (including unfiled drafts) are only reachable through permission-checked views, never a public media URL. Don't move it under `MEDIA_ROOT`.
- **`_can_view_document`/`_can_edit_document`** (`documents/views.py`) is the single source of truth for document access — there was a real IDOR here before (see `WopiEndpointPermissionTests`). Any new document-touching endpoint should route through these, not reinvent a check.
- **URL names are inconsistently hyphenated vs. underscored** across `urls.py` files (`second-reading` vs. `floor_amendments`, etc. — see the 6-redirect bug above). Always grep the actual registered `name=` before writing `redirect()`/`reverse()`; don't assume it matches the view function's own name.
- **`Document.status` includes dynamic strings** like `'COMMITTEE [2]'` (hearing count baked in) — queries use `status__icontains='COMMITTEE'`; never assume an exact `==` match is exhaustive.
- **Casual Docs comment-reimport bug**: a comment's anchor can survive a reopen while its text silently vanishes. `documents/docx_comments.py::restore_missing_comments` is a best-effort stopgap, explicitly not a real fix (see its own docstring) — the real fix would be a DB-backed panel.
- **Reference-number assignment** uses a Postgres advisory lock (`_acquire_sequence_lock`) and must stay inside `transaction.atomic()` with the `.save()` before the block exits — a bug here means duplicate legal Ordinance/Resolution numbers.
- **Multi-session concurrent editing is real, not hypothetical**: `final-lepmits-4c`/`-5f`/`-53`/`-46` were all active peer sessions during this work. CLAUDE.md's coordination rules (check `git diff --stat` before editing hot files, use `ListAgents`/`SendMessage`) apply for real.
